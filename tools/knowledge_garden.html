設定

AI（LLM API）

OpenAI 互換の API を利用します。初期値は Groq の無料ティア（https://groq.com で無料でキーを取得、クレジットカード不要）に設定しています。キーはこのブラウザ（localStorage）にのみ保存され、外部には送信されません（API 呼び出しのみに使用）。意味検索は API 不要のローカルスコアで動作します。Embeddings は任意（未入力ならローカル検索を継続）。※ブラウザから直接呼び出すため、プロバイダが CORS を許可している必要があります（Groq/OpenAI 等は対応）。

テーマ

外観を切り替えられます。カスタムではベース（ライト/ダーク）とアクセント色を自由に設定できます。変更はすぐに反映され、このブラウザに保存されます。

クラウド同期（アカウント）

Supabase の無料ティアを使って、どの端末からでも同じアカウントでデータを共有できます（クレジットカード不要・500MB / 50k MAU まで無料）。下の「接続情報」に自分の Supabase プロジェクト URL と anon key を貼り、Google アカウントまたはメールアドレスでログインしてください。URL / key はこのブラウザにのみ保存されます。未設定の場合は今まで通り localStorage のみで動きます。
知り合いだけに共有する場合：このアプリのファイル／URL にはいかなる鍵も書き込まれていません。相手にはファイルを渡すだけで、Supabase の URL ・ anon key と Groq の API key は別途（メッセージ等で）だけ教えてください。そうすればソースコードを見られても鍵は漏れません。さらに Supabase の Authentication 設定で「新規登録を許可」をオフにすると、知らない人が勝手にアカウントを作れなくなります（あなたがユーザーを手動追加）。

Supabase の用意とテーブル作成 SQL（無料）
  1. supabase.com で無料アカウント作成 → New project。
  2. Project Settings → API の Project URL と anon public key をコピーして下の入力欄へ。
  3. SQL Editor で以下を実行（テーブル作成 ＋ 他人アクセス拒否ポリシー）：
create table if not exists kb_cards (
  user_id uuid primary key references auth.users(id) on delete cascade,
  cards jsonb not null default '[]'::jsonb,
  updated_at timestamptz not null default now()
);
alter table kb_cards enable row level security;
create policy "own row" on kb_cards
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

※Auth 設定で「Email confirmations」をオフにすると、登録後すぐにログインできます（オンのままなら確認メールのリンクを踏んでからログイン）。

Google ログインを使う場合： Supabase の Authentication → Providers で Google を有効化し、Google Cloud で作成した OAuth クライアント ID / シークレットを貼ります。さらに Authentication → URL Configuration の Redirect URLs に、以下の URL をそのまま（末尾スラッシュなし）追加してください：
https://7bf76b18915b4f2983eee9f43e3eb3a0.gz1.agentos-app.net
※Google ログインは必ずこのデプロイ版で完了し、クラウド同期もこの URL でご利用ください（planter から押してもここに移動します）。
